# ⚗ 化学扑克（Chemistry Poker）

基于人教版高中化学知识体系的回合制对战卡牌游戏。纯前端实现（原生 ES Module，无构建工具），围绕真实化学反应规律出牌对拼，兼顾知识复习与策略博弈。

## 快速开始

### 环境要求

- Node.js 18 及以上（仅用于启动本地静态服务器与运行测试）
- 现代浏览器（Chrome / Edge / Firefox / Safari，需支持 ES Module）

### 方式一：使用内置服务器（推荐）

1. 在项目根目录打开终端（Windows PowerShell / macOS / Linux 均可）。
2. 启动服务：

```bash
npm start
```

3. 终端出现 `化学扑克已启动` 后，在浏览器访问（两种方式等价）：

```
http://localhost:8080        （IP:端口，始终可用）
http://www.chemistry-poker.cn （自定义域名，需按下文配置 hosts）
```

4. 在首页依次选择「对战模式」→ 勾选「知识范围」→ 设置手牌数与难度 → 点击「开始对战」即可游玩。
5. 结束游玩时回到终端按 `Ctrl + C` 停止服务。

### 使用自定义域名访问（可选，推荐一次配置）

服务器同时监听 `80`（供域名直接使用）与 `8080`（IP 备用）两个端口，互不冲突；某端口被占用时自动跳过并保留另一端口。

1. 以管理员身份打开 PowerShell，追加 hosts 映射（仅首次需要）：

```powershell
Add-Content 'C:\Windows\System32\drivers\etc\hosts' "`r`n127.0.0.1 chemistry-poker.cn`r`n127.0.0.1 www.chemistry-poker.cn" -Encoding ASCII
```

macOS / Linux 对应文件为 `/etc/hosts`：

```bash
echo "127.0.0.1 chemistry-poker.cn" | sudo tee -a /etc/hosts
echo "127.0.0.1 www.chemistry-poker.cn" | sudo tee -a /etc/hosts
```

2. `npm start` 启动后，浏览器直接访问 `http://www.chemistry-poker.cn` 即可，所有静态资源均为相对路径，无需其他改动。
3. 不想占用 80 端口时，可只运行 `npm run start:ip`（仅 8080），再用 `http://www.chemistry-poker.cn:8080` 访问。
4. 域名可通过环境变量更换：`CHEMISTRY_POKER_DOMAIN=my.game.cn npm start`（Windows PowerShell 用 `$env:CHEMISTRY_POKER_DOMAIN='my.game.cn'; npm start`），hosts 映射同步改为新域名即可。
5. 移除方式：删除 hosts 中 `# Chemistry Poker (local dev)` 标记的对应行。

### 方式二：使用其他静态服务器

项目为纯前端（原生 ES Module，无构建步骤），任意静态服务器托管项目根目录即可：

```bash
# Python 3
python -m http.server 8080

# 或使用 VS Code 的 Live Server 插件，右键 index.html → Open with Live Server
```

> 注意：不能直接双击 `index.html` 用 `file://` 打开，浏览器会因同源策略拦截 ES Module 加载，导致页面空白。必须通过 HTTP 服务访问。

### 端口被占用怎么办

内置服务器默认监听 `80` 与 `8080` 两个端口，单个端口被占用时会自动跳过并继续提供另一端口。两个端口都被占用时才需要处理：

```powershell
# Windows：查找并结束占用端口的进程
Get-NetTCPConnection -LocalPort 80,8080 | Select-Object -ExpandProperty OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
```

也可以用 `node server.js --port=8090` 指定任意单端口启动（对应 `npm run start:ip` 为仅 8080）。

## 联机对战

v2.7.0 起支持双人实时联机对战（基于 WebSocket，服务端权威）。

### 附近玩家（v2.8.0）

大厅菜单中的「📍 附近玩家」会按地理位置检索在线玩家，并按距离由近到远展示：

1. 优先使用浏览器 GPS 定位；HTTP（非 localhost）或定位失败时自动回退到「城市兜底」坐标。
2. 面板每 10 秒自动刷新附近玩家状态（空闲 / 房间中 / 对局中）与距离。
3. 「邀请对战」会为发起者自动创建房间并向对方推送邀请，对方接受后按普通加入流程进入房间；
   若对方正在房间中，面板会提供「加入房间号」按钮直接入房。
4. 隐私设置：可关闭「公开位置」（关闭后不会出现在他人的附近列表），并设置自己的可被搜索范围（5/10/30/100 km 或不限）。
   检索为双向过滤——既要落在自己的搜索范围，也要落在对方的可被搜索范围。
5. 弱网友好：单次请求 8 秒超时，失败后按 1s→2s 指数退避自动重试 3 次，并保留上一次的列表与明确的加载 / 错误状态。
6. 服务端单次最多返回 50 人，距离使用 haversine 球面公式计算（`js/net/geo.js`，前后端共用）。

### 本地联机

1. `npm start` 启动服务器（默认监听 80 与 8080 端口）。
2. 房主在设置页点击「🌐 联机对战」→「创建房间」，获得 6 位房间号。
3. 对手在同一局域网的另一台设备浏览器访问 `http://<服务器IP>:8080`，进入「联机对战」→「加入房间」，输入房间号。
4. 双方就绪后，房主点击「开始对战」即可实时对弈。

### 暴露到公网（让任意网络的玩家加入）

服务器启动后默认监听本机，外部网络无法直接访问。可通过以下任一方式对外暴露：

- **端口映射 / 公网 IP**：若服务器有公网 IP 或路由器支持端口映射，将 8080 端口映射到公网，对手直接访问 `http://<公网IP>:8080`。
- **内网穿透**：使用 frp、ngrok、cloudflared 等工具把本地 8080 端口映射到公网域名。
  ```bash
  # 示例：cloudflared
  cloudflared tunnel --url http://127.0.0.1:8080
  ```
- **云服务器部署**：把项目部署到云服务器，开放 80/8080 端口，对手访问服务器域名即可。

> 联机客户端使用同源 WebSocket（`ws://当前域名`），无需在代码中硬编码服务器地址，更换域名 / IP 后自动适配。

## 对战模式

| 模式 | 卡组来源 | 核心玩法 |
|---|---|---|
| 化学物质模式 | 无机化学、有机化学专题 | 酸碱中和、金属置换、氧化物与酸碱、有机转化链与检验 |
| 离子模式 | 离子反应与共存、离子氧化还原专题 | 离子共存判断、沉淀/气体/弱电解质生成、离子氧化还原、组合技 |

## 规则摘要

- 初始先手随机，每回合由先手方出牌，对方应答或放弃，回合赢家成为下一回合先手。
- 应答判定优先级：特征反应方程式（×2）→ 离子相互作用（×2）→ 类别通用规律（×1.5）→ 匹配失败（先手方获胜）。
- 回合得分 =（先出牌点数 + 应答牌点数）× 倍率 + 连胜加成（每连胜 +2，最多 +10）。
- 放弃应答不消耗手牌，先手方按「先出牌点数 ×1」得分；放弃方不得分。
- 离子模式集齐组合技所需离子且应答成功时，倍率再乘组合 bonus，日志标注 ⚡组合技。
- 任一方手牌打空即结束，总分高者获胜。

游戏首页「查看规则」按钮可随时打开完整规则弹窗。
