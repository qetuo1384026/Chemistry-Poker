# ⚗ 化学扑克（Chemistry Poker）

基于人教版高中化学知识体系的回合制对战卡牌游戏。纯前端实现（原生 ES Module，无构建工具），围绕真实化学反应规律出牌对拼，兼顾知识复习与策略博弈。

## 快速开始

```bash
npm start      # 启动本地服务，默认 http://localhost:8080
npm test       # 运行全部测试（基础用例 + 系统性用例）
```

也可直接使用任意静态服务器托管项目根目录（浏览器需支持 ES Module）。

## 对战模式

| 模式 | 卡组来源 | 核心玩法 |
|---|---|---|
| 化学物质模式 | 无机化学、有机化学专题 | 酸碱中和、金属置换、氧化物与酸碱、有机转化链与检验 |
| 离子模式 | 离子反应与共存、离子氧化还原专题 | 离子共存判断、沉淀/气体/弱电解质生成、离子氧化还原、组合技 |

## 规则摘要

- 初始先手随机，每回合由先手方出牌，对方应答或放弃，回合赢家成为下一回合先手。
- 应答判定优先级：特征反应方程式（×2）→ 离子相互作用（×2）→ 类别通用规律（×1.5）→ 匹配失败（先手方获胜）。
- 回合得分 =（先出牌点数 + 应答牌点数）× 倍率 + 连胜加成（每连胜 +2，最多 +10）。
- 放弃应答不消耗手牌，先手方按「先出牌点数 ×1」得分；放弃方不得分。
- 离子模式集齐组合技所需离子且应答成功时，倍率再乘组合 bonus，日志标注 ⚡组合技。
- 任一方手牌打空即结束，总分高者获胜。

游戏首页「查看规则」按钮可随时打开完整规则弹窗。

## 目录结构

```
index.html          首页 / 对战 / 结算三界面 + 规则弹窗
css/style.css       全局样式与响应式布局
js/main.js          入口：界面切换、对局生命周期、规则弹窗
js/ui/setup.js      模式与知识范围选择
js/ui/board.js      对战界面与回合驱动
js/core/game.js     对局状态机
js/core/rules.js    匹配规则引擎（含离子判定与组合技检测）
js/core/scoring.js  计分规则
js/data/            无机 / 有机 / 离子卡牌与反应数据
tests/              Node 断言测试
server.js           本地静态服务器（端口 8080）
```

## 版本与更新记录规范

1. 采用语义化版本：修复类发版递增补丁号，功能新增递增次版本号，不兼容重构递增主版本号。
2. 每次发布（无论大小版本）必须在下方「更新记录」中新增一条记录，置于列表最前。
3. 记录需按 **新增 / 修复 / 优化** 分类列出具体条目，避免含糊描述，便于回溯与验收。
