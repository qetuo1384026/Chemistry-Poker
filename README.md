# ⚗ 化学扑克（Chemistry Poker）

基于人教版高中化学知识体系的回合制对战卡牌游戏。纯前端实现（原生 ES Module，无构建工具），围绕真实化学反应规律出牌对拼，兼顾知识复习与策略博弈。

## 快速开始

### 环境要求

- Node.js 18 及以上（仅用于启动本地静态服务器与运行测试）
- 现代浏览器（Chrome / Edge / Firefox / Safari，需支持 ES Module）

### 方式一：使用内置服务器（推荐）

1. 在项目根目录打开终端（Windows PowerShell / macOS / Linux 均可）。
2. 启动服务：

```bash
npm start
```

3. 终端出现 `化学扑克已启动: http://localhost:8080` 后，在浏览器访问：

```
http://localhost:8080
```

4. 在首页依次选择「对战模式」→ 勾选「知识范围」→ 设置手牌数与难度 → 点击「开始对战」即可游玩。
5. 结束游玩时回到终端按 `Ctrl + C` 停止服务。

### 方式二：使用其他静态服务器

项目为纯前端（原生 ES Module，无构建步骤），任意静态服务器托管项目根目录即可：

```bash
# Python 3
python -m http.server 8080

# 或使用 VS Code 的 Live Server 插件，右键 index.html → Open with Live Server
```

> 注意：不能直接双击 `index.html` 用 `file://` 打开，浏览器会因同源策略拦截 ES Module 加载，导致页面空白。必须通过 HTTP 服务访问。

### 端口被占用怎么办

内置服务器固定监听 8080。若提示端口被占用（`EADDRINUSE`），可先释放端口：

```powershell
# Windows：查找并结束占用 8080 的进程
Get-NetTCPConnection -LocalPort 8080 | Select-Object -ExpandProperty OwningProcess | ForEach-Object { Stop-Process -Id $_ -Force }
```

或把 `server.js` 末尾的 `listen(8080, ...)` 与提示文字改为其他端口（如 8090）后重新 `npm start`。

### 运行测试

```bash
npm test
```

将依次执行基础用例与系统性用例（当前共 54 项），全部通过即表示核心规则与对局逻辑正常。

## 对战模式

| 模式 | 卡组来源 | 核心玩法 |
|---|---|---|
| 化学物质模式 | 无机化学、有机化学专题 | 酸碱中和、金属置换、氧化物与酸碱、有机转化链与检验 |
| 离子模式 | 离子反应与共存、离子氧化还原专题 | 离子共存判断、沉淀/气体/弱电解质生成、离子氧化还原、组合技 |

## 规则摘要

- 初始先手随机，每回合由先手方出牌，对方应答或放弃，回合赢家成为下一回合先手。
- 应答判定优先级：特征反应方程式（×2）→ 离子相互作用（×2）→ 类别通用规律（×1.5）→ 匹配失败（先手方获胜）。
- 回合得分 =（先出牌点数 + 应答牌点数）× 倍率 + 连胜加成（每连胜 +2，最多 +10）。
- 放弃应答不消耗手牌，先手方按「先出牌点数 ×1」得分；放弃方不得分。
- 离子模式集齐组合技所需离子且应答成功时，倍率再乘组合 bonus，日志标注 ⚡组合技。
- 任一方手牌打空即结束，总分高者获胜。

游戏首页「查看规则」按钮可随时打开完整规则弹窗。

## 目录结构

```
index.html          启动封面 / 选择 / 对战 / 结算四界面 + 规则与关于弹窗
css/style.css       全局样式与响应式布局
js/main.js          入口：封面加载与入口、界面切换、对局生命周期、弹窗
js/ui/setup.js      模式与知识范围选择
js/ui/board.js      对战界面与回合驱动
js/core/game.js     对局状态机
js/core/rules.js    匹配规则引擎（含离子判定与组合技检测）
js/core/scoring.js  计分规则
js/data/            无机 / 有机 / 离子卡牌与反应数据
tests/              Node 断言测试
server.js           本地静态服务器（端口 8080）
```

### v2.3.0

**修复**
- 规则弹窗右上角关闭叉号点击无响应：该按钮缺少 `data-close` 标记，事件委托未能命中；已补全标记，点击立即关闭弹窗。

**新增**
- 化学物质模式新增 18 张卡：无机 10 张（Fe₃O₄、AlCl₃、FeSO₄、MgO、KOH、HBr、SO₃、KClO₃、P₄、CuS），有机 8 张（丙烷、一氯甲烷、甲醇、丙三醇、苯甲酸、乙酸甲酯、果糖、纤维素）。
- 离子模式新增 7 张离子卡（Zn²⁺、Mn²⁺、F⁻、SO₃²⁻、SiO₃²⁻、PO₄³⁻、CH₃COO⁻），新增 18 组离子相互作用（含沉淀、气体、氧化还原、弱电解质生成）。
- 新增 2 个离子组合技：「亚硫酸还原链」「磷酸银黄沉」，组合技总数达 7 个。
- 反应方程式库新增 36 条（总计 160 条），易错解析新增 3 条（CuS 不溶于稀盐酸、苯甲酸不能银镜、果糖不能使溴水褪色）。

**优化**
- 离子判定顺序调整：显式登记的相互作用优先于「同号必共存」判断，使 HCO₃⁻ + OH⁻、I⁻ + MnO₄⁻ 等真实存在的同号反应可正确触发；未登记的同号离子仍判为共存。
- 新增卡牌数据校验用例：卡牌 id 唯一、字段完整、点数范围、方程与离子作用表引用有效性、同号例外约束、各模式加载覆盖。
